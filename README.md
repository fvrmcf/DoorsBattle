# DOORS Battle

Виртуальный симулятор открытия кейсов в тематике Roblox DOORS.
Никакого доната, никаких реальных денег — чисто развлекательный проект.

## Функции
- 🎁 4 вида кейсов с разными шансами редкости
- ⬆️ Система апгрейда предметов (риск/шанс)
- 💰 Продажа предметов за виртуальные монеты
- 🏆 Система достижений
- 📊 Статистика игрока
- 💾 Сохранение прогресса в localStorage
